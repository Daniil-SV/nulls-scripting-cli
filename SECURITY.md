# Security Policy

## Reporting a vulnerability

Do not open a public issue for security problems.

Report vulnerabilities privately through GitHub Security Advisories:

https://github.com/Daniil-SV/nulls-scripting-cli/security/advisories/new

Include steps to reproduce, affected versions, and any relevant logs. Remove
tokens, cookies, account identifiers, and other secrets before posting.

## Scope

This project stores local login sessions. Never share files from the
`nulls-scripting` or `nulls-connect` config directories, and never paste
`auth_token` or Connect bearer tokens into an issue.
